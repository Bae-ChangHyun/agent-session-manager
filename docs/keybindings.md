# 키보드 단축키

cc-tui는 마우스 없이 키보드만으로 모든 기능을 사용할 수 있습니다.

## 전역

| 키 | 동작 |
|:---:|:---|
| `F1` | Dashboard 탭 |
| `F2` | Projects 탭 |
| `F3` | File History 탭 |
| `F4` | Debug/Todos 탭 |
| `F5` | Migrate 탭 |
| `F6` | Backups 탭 |
| `q` | 앱 종료 |
| `r` | 전체 데이터 새로고침 |
| `Tab` | 위젯 간 포커스 이동 |
| `↑` / `↓` | 목록/테이블 행 탐색 |
| `Enter` | 항목 선택/펼치기 |

## Dashboard (F1)

| 키 | 동작 |
|:---:|:---|
| `1` | Daily 사용량 보기 |
| `2` | Weekly 사용량 보기 |
| `3` | Monthly 사용량 보기 |

## Projects (F2)

| 키 | 동작 |
|:---:|:---|
| `↑` / `↓` | 트리 탐색 |
| `Enter` | 프로젝트 펼치기 / 세션 상세 보기 |
| `d` | 선택한 세션 삭제 |
| `D` | Orphaned 세션 전체 삭제 |
| `x` | 선택한 프로젝트 설정 제거 |

## File History (F3)

| 키 | 동작 |
|:---:|:---|
| `↑` / `↓` | 항목 탐색 |
| `Space` | 다중 선택 토글 (녹색 ● 표시) |
| `d` | 삭제 (선택 항목 > 그룹 > 커서 항목 우선순위) |
| `D` | Orphaned 전체 삭제 |

## Debug / Todos (F4)

| 키 | 동작 |
|:---:|:---|
| `↑` / `↓` | 항목 탐색 |
| `Tab` | Debug 테이블 ↔ Todo 테이블 포커스 전환 |
| `Space` | 다중 선택 토글 |
| `d` | 삭제 (포커스된 테이블 기준) |
| `D` | Orphaned 전체 삭제 (포커스된 테이블 기준) |
| `p` | 빈 파일 정리 (포커스된 테이블 기준) |

## Backups (F6)

| 키 | 동작 |
|:---:|:---|
| `↑` / `↓` | 백업 목록 탐색 |
| `c` | Config 백업 생성 |
| `b` | Full 백업 생성 |
| `R` | 선택한 백업 복원 |
| `d` | 선택한 백업 삭제 |

## 확인 다이얼로그

| 키 | 동작 |
|:---:|:---|
| `y` | 확인 |
| `n` / `Esc` | 취소 |
| `←` / `→` | 버튼 포커스 이동 |
| `Enter` | 포커스된 버튼 실행 |

## 삭제 우선순위

`d` 키를 눌렀을 때의 동작 우선순위:

1. **다중 선택 항목이 있으면** → 선택된 항목 전체 삭제
2. **커서가 그룹 헤더 위에 있으면** → 해당 그룹 전체 삭제
3. **그 외** → 커서가 위치한 단일 항목 삭제
